## ✨ Funcionalidades

- Leitura de arquivos EPUB
- Alteração de tema (claro/escuro)
- Controle de tamanho da fonte
- Destaque de texto
- Tradução integrada
- Biblioteca de livros

## 🛠 Tecnologias

- Kotlin
- Android SDK
- WebView
- Jetpack Components
